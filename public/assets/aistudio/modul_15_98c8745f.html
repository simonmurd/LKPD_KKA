Contra: Run and Gun Side-Scroller & Platform Physics Engine!

Selamat datang di Modul Puncak 15, Developer Game! 🎖️ Game aksi klasik bergenre run and gun ini menggabungkan seluruh kompleksitas pemrograman game 2D: fisika gravitasi & pijakan platform, penanganan input multi-arah, serta manajemen entitas ganda (pemain, musuh, dan peluru).

Misi ini dikemas dalam 20 Tugas Terstruktur yang harus kamu selesaikan pada kode di editor tengah.

🎯 Cara Mengerjakan:
Cari petunjuk 🎯 TUGAS 1 sampai TUGAS 20 pada editor kode. Baca instruksi komentar, lalu isi nilai atau hapus tanda tanya ('?') dengan ekspresi JavaScript yang tepat.

Setelah selesai, klik "✨ Sinkronisasi Kode". Gunakan tombol keyboard (Panah Kiri/Kanan/Atas, Spasi untuk Lompat, X untuk Tembak) atau tombol kontrol virtual pada layar pratinjau!
💡 Konsep Kunci Modul 15:
• Penanganan Multi-Key Input: Menggunakan addEventListener('keydown') dan keyup untuk mendukung kombinasi tombol bergerak sambil melompat dan menembak.
• Fisika Gravitasi & Platform Collision: Menambahkan akselerasi gravitasi (dy += gravity) serta pemeriksaan batas platform untuk menghentikan jatuh dan mengizinkan lompatan ulang.
• Manajemen Array Entitas Terpusat: Mengelola siklus hidup peluru pemain (playerBullets[]) dan musuh (enemies[]) secara dinamis.
• AABB Collision Detection: Menguji tabrakan kotak (Axis-Aligned Bounding Box) antara peluru dengan musuh dan musuh dengan pemain.
