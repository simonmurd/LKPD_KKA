📜 Modul Instruksi

🍰 Cake Mania / Diner Dash Engine!

Selamat datang di Modul 06, Game Developer! 🍰 Game bergenre Time-Management ini membawa kamu untuk memahami konsep pemrograman berbasis waktu (temporal/timer logic) dan manajemen status dinamis (dynamic state management) yang sangat relevan dengan aplikasi dunia nyata (seperti sistem antrean atau dasbor kasir modern).

Misi kamu adalah menyelesaikan 20 Tugas Terstruktur pada editor kode di bagian tengah untuk mengaktifkan sistem timer kesabaran pelanggan, alur pemesanan makanan, proses memasak di dapur, hingga pengumpulan poin/uang!

🎯 Cara Mengerjakan:
Cari petunjuk 🎯 TUGAS 1 sampai TUGAS 20 pada editor kode. Baca instruksi komentar, lalu isi nilai atau hapus tanda tanya ('?') dengan nilai atau ekspresi JavaScript yang tepat.

Setelah selesai, klik "✨ Sinkronisasi Kode". Kamu dapat mencoba langsung simulasi restoran Cake Mania pada panel output kanan!
💡 Konsep Kunci Modul 06:
• Interval Management (setInterval): Mengurangi tingkat kesabaran pelanggan secara berkala setiap detik secara real-time.
• Timeout Delay (setTimeout): Mensimulasikan durasi waktu proses memasak kue/makanan di dapur.
• Event-Driven Interactions (addEventListener): Merespons klik pemain pada meja restoran sesuai alur layanan.
• State Machine Berjenjang: Perubahan status pelanggan dari WAITING_ORDER ➔ COOKING ➔ READY_TO_SERVE ➔ EATING / ANGRY.
