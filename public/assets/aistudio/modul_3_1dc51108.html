Halo, Seniman Digital! 🖌️ Hari ini kita akan menggunakan JavaScript dan HTML Canvas untuk menggambar sebuah pemandangan alam lengkap dengan rumah dan matahari.

Di editor kode, terdapat 20 Tugas (🎯 TUGAS 1 - 20) yang menunggu untuk kamu selesaikan.

🎯 Cara Mengerjakan:
Cari tulisan 🎯 TUGAS di dalam editor kode, baca instruksinya, lalu ubah nilai atau kodenya.

💡 Tips Keyboard:
  • Gunakan tombol Tab untuk indentasi (2 spasi).
  • Tekan Ctrl + Enter (atau Cmd + Enter) untuk langsung menjalankan kode!
