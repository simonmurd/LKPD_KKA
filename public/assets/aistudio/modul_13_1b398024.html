🏎️ Nitro Street Racing: Top-Down Scrolling & Nitro Boost Engine!

Selamat datang di Modul 13, Developer Game! Modul balapan jalanan bergaya top-down 2D ini mengajarkan cara menciptakan ilusi kecepatan (scrolling movement), manajemen akselerasi Nitro Boost, dan deteksi tabrakan kendaraan (AABB Collision).

Misi ini menguji logika percabangan kompleks, input keyboard multi-tombol, dan manajemen sumber daya bahan bakar melalui 20 Tugas Terstruktur yang harus kamu selesaikan pada editor di tengah.

🎯 Cara Mengerjakan:
Cari petunjuk 🎯 TUGAS 1 sampai TUGAS 20 pada editor kode. Baca instruksi komentar, lalu isi nilai atau hapus tanda tanya ('?') dengan ekspresi JavaScript yang tepat.

Setelah selesai, klik "✨ Sinkronisasi Kode". Kamu dapat mengontrol mobil balap menggunakan Keyboard PC (Panah/WASD + Spasi/Shift untuk Nitro) atau Tombol Virtual pada layar!
💡 Konsep Kunci Modul 13:
• Ilusi Gerakan & Game Loop (Scrolling Movement): Menggerakkan elemen garis jalanan dan mobil musuh ke arah bawah secara terus-menerus untuk memberi kesan visual mobil pemain sedang melaju kencang.
• Event Listener Multi-Key: Menggunakan keydown & keyup untuk mengontrol kemudi (ArrowLeft, ArrowRight) dan aktivasi Nitro Boost (Spasi / Shift).
• Mekanika Nitro & Resource Management: Saat Nitro aktif (isNitroActive), kecepatan maksimal digandakan dan bahan bakar (nitroFuel) berkurang. Saat mati, bahan bakar akan teregenerasi perlahan.
• Deteksi Tabrakan (AABB Collision): Mengukur tumpang-tindih area bounding box antara mobil pemain dan rintangan mobil lawan di lintasan.
• State Management Terpusat: Melacak skor (jarak tempuh), kecepatan (speed), bahan bakar nitro (nitroFuel), dan nyawa pemain.
