Prince of Persia (J2ME): Acrobatic Platformer & Timed State Engine!

Selamat datang di Modul 18 (Ultimate Milestone), Developer Game! 🗡️ Mengembangkan simulasi *Prince of Persia* klasik versi J2ME adalah mahakarya tingkat lanjut. Game ini menguji penguasaan animasi status bersyarat (Acrobatic State Machine), manajemen waktu sesi global (Countdown Timer Logic), dan presisi interaksi lingkungan (Hazard Detection & Ledge Grabbing).

Selesaikan **20 Tugas Terstruktur** pada editor terminal untuk melengkapi logika game fisika pangeran ini.

🎯 Cara Mengerjakan:
Cari petunjuk 🎯 TUGAS 1 sampai TUGAS 20 pada editor kode di tengah. Baca instruksi komentar, lalu isi nilai atau hapus tanda tanya ('?') dengan ekspresi JavaScript yang tepat.

Setelah selesai, klik "✨ Sinkronisasi Kode". Kamu dapat mengontrol Pangeran menggunakan Keyboard PC (Panah/WASD) atau D-Pad Virtual pada layar preview!
💡 Konsep Kunci Modul 18:
• State Machine Akrobatik: Mengatur status karakter yang saling terikat: IDLE, RUNNING, JUMPING, LEDGE_GRAB, FALLING, hingga HURT.
• Countdown Timer Logic: Menggunakan interval 1000ms untuk menghitung mundur durasi sesi permainan (timeLeft--). Jika waktu habis, pemicu status TIME_UP diaktifkan.
• Precision Ledge Detection: Mendeteksi saat pangeran berada tepat di tepi dinding tinggi untuk memicu status bergantung (LEDGE_GRAB).
• Environmental Hazard (Spike Trap): Deteksi tabrakan presisi dengan duri tajam di lantai yang mengurangi nyawa dan memicu *respawn*.
