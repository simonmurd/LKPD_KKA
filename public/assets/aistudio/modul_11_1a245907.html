Physics & 2D Array Grid: Retro Brick Breaker Engine!

Selamat datang di Modul 11, Developer Game! 🕹️ Di modul pengembangan game tingkat lanjut ini, kamu akan membangun studi kasus klasik Retro Brick Breaker Engine menggunakan JavaScript, Canvas HTML5, dan konsep 2D Array Grid Management.

Misi ini menguji pemahaman fisika pantulan dan manipulasi array multi-dimensi melalui 20 Tugas Terstruktur yang harus kamu selesaikan pada kode di editor tengah.

🎯 Cara Mengerjakan:
Cari petunjuk 🎯 TUGAS 1 sampai TUGAS 20 pada editor kode. Baca instruksi komentar, lalu isi nilai atau hapus tanda tanya ('?') dengan ekspresi JavaScript yang tepat.

Setelah selesai, klik "✨ Sinkronisasi Kode". Kamu dapat mengontrol papan (paddle) menggunakan Keyboard PC (Panah Kiri/Kanan atau A/D), Mouse, atau Tombol Virtual!
💡 Konsep Kunci Modul 11:
• 2D Array Matrix Grid: Mengelola matriks balok dua dimensi (baris dan kolom) serta melacak status aktif/hancur (status: 1 / 0).
• Vektor & Fisika Pantulan: Mengubah arah gerak bola (dx & dy) saat menabrak dinding, papan (paddle), atau balok.
• AABB & Circle Collision: Pengecekan tabrakan presisi antara koordinat bola bundar dan area balok kotak.
• State Management Terpusat: Melacak skor, sisa nyawa, serta status permainan (PLAYING, GAME_OVER, WIN).
