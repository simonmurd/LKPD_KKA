🚀 Modul 4: Pairs / Memory Match Game (DOM & State Focus)
📜 Modul Instruksi

Memory Match: DOM & State Management Engine!

Selamat datang di Modul 4, Web Developer! 🧠 Game Memory Match (Pairs) adalah proyek ideal untuk menguasai manipulasi DOM, manajemen status (State Management), dan animasi CSS 3D tanpa kompleksitas elemen Canvas.

Misi ini melatih kemampuanmu dalam event handling, memvalidasi pencocokan dua kartu, serta mengunci layar secara temporer melalui 20 Tugas Terstruktur pada editor kode.

🎯 Cara Mengerjakan:
Cari petunjuk 🎯 TUGAS 1 sampai TUGAS 20 pada editor kode di tengah. Baca komentar instruksi, lalu ganti tanda tanya ('?') dengan nilai atau ekspresi JavaScript/CSS yang tepat.

Setelah selesai, klik "✨ Sinkronisasi Kode" untuk melihat hasil simulasi game di panel sebelah kanan!
💡 Konsep Kunci Modul 4:
• Event Handling (addEventListener): Menangkap event klik pengguna pada setiap elemen kartu untuk memicu aksi pembalikan kartu secara dinamis.
• State Management (Status Aplikasi): Melacak kartu pertama (firstCard), kartu kedua (secondCard), penguncian layar (isLocked), serta jumlah pasangan tercocokkan.
• Logika Percabangan (if/else): Menentukan apakah kartu cocok (dataset.icon === dataset.icon) atau harus dibalik kembali setelah delay setTimeout.
• Animasi CSS 3D: Menggunakan transform: rotateY(180deg) dan backface-visibility: hidden untuk efek balik kartu yang mulus.
