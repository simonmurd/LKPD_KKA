📜 Modul Instruksi

Retro Pac-Man: Grid Navigation & Ghost AI Engine!

Selamat datang di Modul 12 (Capstone Project), Developer Game! 🟡 Pac-Man adalah puncak dari seluruh modul pemrograman game interaktif. Sebagai proyek tingkat lanjut, Pac-Man menguji pemahaman menyeluruh tentang navigasi grid, kecerdasan buatan (AI) hantu, dan manajemen status terpusat.

Misi ini menguji logika percabangan kompleks, input buffering, dan Finite State Machine melalui 20 Tugas Terstruktur yang harus kamu selesaikan pada kode di editor tengah.

🎯 Cara Mengerjakan:
Cari petunjuk 🎯 TUGAS 1 sampai TUGAS 20 pada editor kode. Baca instruksi komentar, lalu isi nilai atau hapus tanda tanya ('?') dengan ekspresi JavaScript yang tepat.

Setelah selesai, klik "✨ Sinkronisasi Kode". Kamu dapat mengontrol Pac-Man menggunakan Keyboard PC (Panah/WASD) atau D-Pad Virtual pada layar!
💡 Konsep Kunci Modul 12:
• Navigasi Grid & Input Buffering: Menggunakan event keydown untuk menyimpan arah pergerakan berikutnya (nextDx, nextDy) sebelum Pac-Man mencapai persimpangan jalur ubin.
• Ghost AI & Finite State Machine: Mengatur pergerakan hantu berdasarkan mode (CHASE vs FRIGHTENED).
• Mode Panik (Power Pellet): Mengubah status hantu menjadi Frightened (warna biru, bergerak lambat, dan bisa dimakan) selama durasi tertentu.
• State Management Terpusat: Melacak status permainan secara real-time: score, lives, status, dan mode.
